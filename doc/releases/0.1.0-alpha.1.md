# BluMach 0.1.0-alpha.1

First public preview of the classic Qt 6 product. The initial historical
collection contains Olivetti PCS 86, PCS 286 and PCS 386SX. Inherited emulator
machines remain available; deferred BluMach models are not new selection choices.

## First run on Windows x86-64

1. Extract the complete ZIP into a writable directory. Keep the DLLs and
   platform-plugin folders together with BluMach.exe.
2. Open BluMach.exe. The collection and saved-machine library open even when
   no usable firmware is installed.
3. In Tools → Preferences, choose the root ROM folder. Its immediate children
   include `machines/` and, where needed, video/device ROM directories. Confirm
   the dialog to save the folder. Open folder and Check again assist setup.
4. Create a machine from its historical sheet. Choose the commercial storage
   profile, supported RAM and optional upgrades. A blank generated HDD still
   needs guest partitioning/formatting and an operating system.
5. Provide local floppy/OS media and start the machine. If required firmware
   is absent, startup explains the problem and leaves the VM configuration intact.

Explicit `--rompath`/`-R` takes priority over the saved folder at startup. A GUI
folder change applies to subsequent launches; existing emulator processes retain
their loaded firmware. Cancelling Preferences does not save a changed folder.

## Separate machine library

The Windows default library is `%USERPROFILE%\BluMach VMs`; portable mode uses
`BluMach VMs` beside the executable. Global preferences live under BluMach's
own application-config directory, not 86Box's. The saved library key is
`blumach_vmm_path`: an older `vmm_path` is deliberately not reused automatically,
even if it points to `86Box VMs`. Existing folders, configurations and disks are
not moved, deleted, renamed or copied. Choose an independent directory in
Preferences; a previous dedicated BluMach folder can be selected explicitly.

The classic engine retains `86box.cfg`/`86box_global.cfg` as compatibility
filenames inside those isolated directories. This does not make the default
libraries shared. Choosing an existing 86Box library or disk explicitly can
still share mutable data: use complete private copies for alpha testing, not
the originals. ROM folders can be shared read-only. Unpack BluMach separately
from 86Box, especially when using portable mode.

## Required firmware layout

These are filenames expected by the implementation, not downloads or grants
of redistribution rights. Supply firmware you are entitled to use.

- PCS 86, BIOS 1.09: `machines/olivetti_pcs86/CSAB05_02-17.BIN` and
  `machines/olivetti_pcs86/CSAB04_02-25.BIN` (32 KiB each).
- PCS 286, BIOS 1.42: `machines/olivetti_pcs286/olivetti_pcs286_bios_v142_low.bin`
  and `machines/olivetti_pcs286/olivetti_pcs286_bios_v142_high.bin` (64 KiB each).
  BIOS 1.37 is a separate selectable set; it does not substitute automatically
  for missing 1.42 files.
- PCS 386SX, BIOS 1.14: `machines/olivetti_pcs386sx/olivetti_pcs386sx_v114_lo.bin`
  and `machines/olivetti_pcs386sx/olivetti_pcs386sx_v114_hi.bin` (64 KiB each).

PCS 286 RAM choices are 1, 2 and 4 MiB in both creation and Settings. An older
3 MiB profile remains unchanged when read; choose a supported value explicitly
before saving or starting it. Missing firmware never changes the chosen machine
or video card to another available model.

## Validation and limits

The owner reports successful quick audio checks of AdLib and Sound Blaster
through Pro 2.0. Exact machine/software combinations were not supplied and the
full configuration matrix was not tested. Audio upgrades remain experimental,
especially card families outside that report. Preserve the machine sheets'
hardware approximations and pending software coverage.

Before public publication, review the packaged build with fresh profiles of
all three PCS models: POST/boot, keyboard, disk access and persistence,
pause/resume, reset, close and reopen. Windows x86-64 is the first distributed
package; CI compilation on other platforms is not a claim of release acceptance.

The release ZIP includes neither ROMs nor OS/application media. A build manifest
and SHA-256 accompany the archive. To report a problem include the alpha version,
machine/BIOS choice, RAM, disk geometry, sound card and steps to reproduce. A
startup log can be enabled with `--logfile path` (`-L path`).
