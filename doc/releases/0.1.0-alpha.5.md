# BluMach 0.1.0-alpha.5 — classic Windows preview

Fifth experimental preview of the classic Qt 6 product. Downloads are listed
on the
[GitHub release page](https://github.com/BluMach/BluMach/releases/tag/v0.1.0-alpha.5).
CoreMach is a separate project: this preview uses the classic emulator, not
the portable engine.

## Changes since alpha.4

- Catalogue creation and configuration selection for more Olivetti
  machines: the M300 series (M300 with the IF378 board, M300-02, M300-02F,
  M300-08, M300-15, M300-30 and M300-30P), the PCS 11, PCS 33 and PCS 46/C,
  and the M290 SP.
- Olivetti BA013 boards (M300-02/02F, PCS 11/33):
  - The IDE emulation accepts READ BUFFER (E4h) right after IDENTIFY, as
    the BIOS issues it. The hard disk was ready only after a 10-15 second
    timeout before.
  - The keyboard controller reports the front-panel key switch as unlocked
    on the M300-02 and M300-02F.
- M300 IF378: the BIOS sizes memory through the Intel 82335. M300-30: the
  board configuration register and the bus-speed code read by Diagnostics
  1.03/1.04 are emulated.
- Olivetti M290 SP (BIOS 1.08, VLSI TOPCAT): Resident Diagnostics complete
  and MS-DOS boots from the hard disk. The TOPCAT follows the BA-08 bank
  layout (two soldered 512 KB banks plus SIMM banks, 1 to 17 MB); the PIT
  loop test, the refresh check at POST 44h and the board line read with
  keyboard-controller commands 8Ah/8Bh match what the BIOS expects.
- The M300 and PCS profiles run on the interpreter instead of the dynamic
  recompiler.
- Collection:
  - The PCS 46/C belongs to the PCS family; the PCS comparison table gains
    year and BluMach-catalogue columns and rows for the PCS 286 S, PCS 44
    (historical reference) and PCS 46/C.
  - Family tables state the same status and dates as the machine sheets.
  - Periods written as prose ("late 1980s") are translated.
  - The M250, M250 E, M280 and PCS 11 carry an "in development" notice.
    They can still be created; reports help finish them.
- Machine sheets record the new findings in the five languages.

Amstrad PC1512 is not part of the curated collection. Inherited emulator
machines remain selectable independently of the curated collection.

## Setup and firmware

The [alpha.1 setup guide](0.1.0-alpha.1.md) still describes ZIP extraction,
the independent BluMach VM library, configuration filenames and root ROM
folder selection. Each machine sheet identifies its required firmware and
creation choices. Place entitled local firmware under the root ROM folder
selected in Preferences. The configuration combo requires both release
eligibility and locally available machine firmware; the catalogue can be
browsed without it.

ROMs, BIOS, operating systems, applications and private preservation inputs
must not be included in source or binary release assets.

## Known limits

- The VLSI TOPCAT is a partial functional model. The M290 SP timer timing
  and board line are set to what the BIOS checks, not measured on a board.
- M290 SP: the extended Setup opens with Shift+Ctrl+Alt+Del, which Windows
  intercepts, so it cannot be reached yet.
- PCS 46/C: the Setup does not open from the keyboard.
- M300-15: with drive 2 set to AUTO and no second disk, the BIOS waits
  before giving up; this is BIOS behaviour.
- The BA013 boards expose two serial ports; whether the board wires both is
  still being checked.
- The M280 SETUP cannot save its configuration yet: the Olivetti extended
  keyboard-controller protocol is enabled only on the M380.
- The new machines are experimental or partial unless their sheet states
  otherwise.

## Validation and follow-up

Automated catalogue and configuration tests are regression checks, not proof
of complete hardware fidelity. Checked during preparation with original
firmware (not distributed): M300-02F with 2 MB and an IDE disk boots; PCS 33
detects its IDE disk and boots; M300-08 passes POST and Setup and boots
MS-DOS 3.30a from floppy and from an IDE disk in AUTO mode; M300-15 boots
from floppy and from an IDE disk; M300-02 passes POST and boots from floppy;
PCS 46/C passes POST and boots MS-DOS from floppy; M290 SP completes
Resident Diagnostics and boots MS-DOS from its hard disk.

Further acceptance work:

1. M250, M250 E, M280 and PCS 11: POST, Setup and DOS with this build.
2. M300-02: IDE disk. M290 SP: 3, 5, 9 and 17 MB and its extended Setup.
3. PCS 46/C: IDE disk and other RAM populations.

Report bugs with version, host, model, BIOS selection, RAM, storage geometry
and reproduction steps. Enable a startup log with `--logfile path`
(`-L path`) when useful.
