# BluMach 0.1.0-alpha.7 — classic Windows preview

Seventh experimental preview of the classic Qt 6 product. Downloads are listed
on the
[GitHub release page](https://github.com/BluMach/BluMach/releases/tag/v0.1.0-alpha.7).
This preview adds 17 Olivetti machines that can be created from the
catalogue, from the 1984 M24 and M21 to the 1994 M4 Modulo and PCS42P range.
All of them are experimental or partial: their sheets say what has been
checked and what has not.

## Changes since alpha.6

- **Olivetti M24 and M19.** The M24 (8086, internal OGC video, WD1002A-WX1
  hard-disk controller) and the M19 (8088, monochrome 640 × 400) can be
  created from their sheets with BIOS 1.44 and Resident Diagnostics 3.71.
  The OGC video now follows the M24 and M19 timing for the standard 640 × 400
  mode, the real-time clock keeps working, and PIT mode 4 behaves as on the
  hardware in FAST mode. Without a hard disk, the M24 POST can take a while
  before it shows Fixed Disk Not Ready and starts from A:.
- **Olivetti M21**, the transportable sibling of the M24 with an amber OGC
  screen, as an experimental profile with 128 KB and BIOS 1.44.
- **Olivetti M290S** (M203 board, BIOS 1.29) as an experimental profile with
  1, 3 or 5 MB, its EMS and shadow Setup options and a compatible IDE disk.
- **Olivetti M4 Modulo with T.1 boards**: M4-40 and M4-46 (MicroTower) and
  M4-60 and M4-62, with the Olivetti 2.06 service BIOS.
- **Olivetti M4 Modulo with the BA2077 board**: M4-64, M4-65 and M4-66, with
  BIOS R2.03 and IDE disks of the sizes the guide lists.
- **Olivetti Entry with the BA2142 board**: M4-422 S, M4-432 S, M4-452 S and
  PCS42P SX/25, SX/33 and S2/50, with the AMIBIOS PDKK image preserved from a
  physical BA2142. Creation shows that this firmware has not yet been
  matched to each commercial model.
- **A much larger historical catalogue.** Debug builds now show 482 sheets
  for Olivetti, Triumph-Adler, Schneider, Amstrad, Toshiba and TriGem, with filters for documentation, preserved firmware and test
  destination, factory variant groups and the manufacturers' historical
  marks.
- **Release and Debug catalogues.** Release packages carry only the 50
  machines BluMach can emulate, with their texts and photographs. Debug
  builds show every sheet and mark research and hidden sheets with their own
  badge. The catalogue exported for the website with each release holds the
  same 50 machines.
- **Catalogue browsing stays responsive** while preferences are saved.
- **The Unit Tester device** is built only in debug configurations.

## Known limits

- Every new Olivetti machine is experimental or partial. Its sheet lists the
  approximations, the configurations checked and what is still open.
- M4-4x2 S and PCS42P: the BA2142 chipset is an approximation, the flash is
  read-only and the PDKK image has not been matched to each commercial
  model. POST waits about 40 seconds on WAIT... before it shows the
  configuration.
- M4 T.1 and BA2077: the KBC firmware, the physical register defaults and
  other BIOS revisions remain open.
- M19: the optional mouse and the original SCSI controller are not
  emulated; custom CRTC timings are not adjusted.
- The limits listed for alpha.6 and alpha.5 still apply to the other
  machines.

## Validation and follow-up

Automated catalogue and configuration tests are regression checks, not proof
of complete hardware fidelity. Checked during preparation on a local Release
build with the files above: creation from the sheet and power-on to the
POST or boot prompt for the M4-46, M4-65, PCS42P SX/33, M290S, M24, M19 and
M21. The machine sheets record the earlier DOS boot, disk and reset tests
made for each profile.

Report bugs with version, host, model, BIOS selection, RAM, storage geometry
and reproduction steps. Enable a startup log with `--logfile path`
(`-L path`) when useful.
