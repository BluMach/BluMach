# BluMach 0.1.0-alpha.3 — classic Windows preview

Third experimental preview of the classic Qt 6 product, in preparation since
2026-10-14. This document is written ahead of publication; downloads will be
listed on the
[GitHub release page](https://github.com/BluMach/BluMach/releases/tag/v0.1.0-alpha.3)
once the release exists. CoreMach is a separate project: this preview uses
the classic emulator, not the portable engine.

## Changes since alpha.2

- Catalogue creation and configuration selection for five more machines:
  Olivetti PCS 286/S (TI/OLIMCU16 board, BIOS 2.06), Olivetti Prodest PC 1,
  Olivetti Prodest PC 1 HD, Olivetti M28 and Amstrad PC5286. They reuse their
  existing machine-specific implementations; see
  [the candidate notes](next-alpha-machine-candidates.md) for each initial
  scope and remaining acceptance work.
- PCS 286/S creation offers a 12 MHz CPU (default, checked) or 16 MHz
  (experimental). The 1991 PCS 286S is described in the same sheet: its board
  is very probably the same TI/OLIMCU16 design, but the unit's own
  "PCS286S REL. 1.06" EPROMs are not dumped, so 16 MHz runs with BIOS 2.06.
- Olivetti Extended Setup options are kept and applied on PCS 286, TA Dario
  286, PCS 286/S and PCS 386SX:
  - The "frequency (RAM/IO)" item (12/12, 12/6, 6/6 MHz on the 286 boards;
    16/8/16, 16/16/16, 8/8/8 on the PCS 386SX) selects memory and I/O clocks,
    not the CPU clock. BluMach applies it to the AT bus speed and,
    approximately, to memory timing. Olivetti 286 boards default to a 12 MHz
    AT bus.
  - Frequency, keyboard language and password settings now survive a reboot.
    The BIOS clears them at every start when a board input reads as
    "password disabled" (the Dario 286 manual documents this as jumper A11
    "PASSWORT"); the emulated keyboard controller now reports the enabled
    position.
  - PCS 386SX: drive B, shadow RAM and the extended/EMS split chosen in Setup
    are no longer overwritten at start-up.
  - PCS 286: drive B can be chosen when the virtual machine has two floppy
    drives. On the real machine a fitted hard disk leaves room for only one
    internal drive, so the second one represents an external drive.
- Existing virtual machines whose CMOS was never configured in those bytes are
  repaired once with the BIOS's own factory values.
- Triumph-Adler Dario 286 and Dario 386SX are shown in the catalogue. They
  use the same boards as the Olivetti PCS 286 and PCS 386SX and were sold
  while Olivetti owned Triumph-Adler; whether they were Triumph-Adler designs,
  Olivetti commissions or one product under two brands is not documented.
- M28 commercial profile corrected to its documented 5.25-inch 1.2 MB drive.
- Catalogue text review for the new machines and the Olivetti M and Prodest
  families in the five languages.

Amstrad PC1512 is not part of the curated collection. Inherited emulator
machines remain selectable independently of the curated collection.

## Setup and firmware

The [alpha.1 setup guide](0.1.0-alpha.1.md) still describes ZIP extraction,
the independent BluMach VM library, configuration filenames and root ROM
folder selection; [alpha.2](0.1.0-alpha.2.md) adds the M15/T-series notes.
Each new machine sheet identifies its required firmware and creation choices.
Place entitled local firmware under the root ROM folder selected in
Preferences. The configuration combo requires both release eligibility and
locally available machine firmware; the catalogue can be browsed without it.

ROMs, BIOS, operating systems, applications and private preservation inputs
must not be included in source or binary release assets.

## Known limits

- Memory clocked at 6 or 8 MHz is an approximation, not a cycle-accurate model
  of the GC101, HT113 or TACT82300 chipsets.
- The password keyboard-lock mode and the keyboard repeat rate selected in
  Setup are not emulated; the host repeat rate is used.
- PCS 286/S BIOS 2.06 contains Shadow RAM, Extended/Expanded RAM and buzzer
  volume texts that its Setup does not offer on this board.
- The 16 MHz PCS 286/S option and the new machines remain experimental unless
  their sheet states otherwise.

## Validation and follow-up

Automated catalogue and configuration tests are regression checks, not proof
of complete hardware fidelity. Checked during preparation with original
firmware (not distributed): PCS 286 BIOS 1.42 frequency and drive-B Setup
persistence; PCS 286/S BIOS 2.06 at 12 and 16 MHz and its F7 chipset
programming; PCS 386SX BIOS 1.14 8/8/8 persistence and recovery of an
unconfigured CMOS.

Further acceptance work before publication:

1. Smoke-test fresh profiles of the five added machines: POST/boot, keyboard,
   storage, reset, close/reopen and configuration persistence.
2. PCS 386SX: drive B, shadow RAM and EMS persistence after Setup.
3. TA Dario 286: boot with this build.
4. Regression check of PCS 86, PCS 286, PCS 386SX, M15/M15 Plus and the
   Toshiba T models.

Report bugs with version, host, model, BIOS selection, RAM, storage geometry
and reproduction steps. Enable a startup log with `--logfile path`
(`-L path`) when useful.
