# BluMach 0.1.0-alpha.4 — classic Windows preview

Fourth experimental preview of the classic Qt 6 product. Downloads are listed
on the
[GitHub release page](https://github.com/BluMach/BluMach/releases/tag/v0.1.0-alpha.4).
CoreMach is a separate project: this preview uses the classic emulator, not
the portable engine.

## Changes since alpha.3

- Catalogue creation and configuration selection for more machines: TriGem
  SX386M (KS-II board, AMI BIOS DG2X-6080-020491-KB) and the Olivetti M250,
  M250 E, M280 and M380/M380 C. See
  [the candidate notes](next-alpha-machine-candidates.md) for each initial
  scope and remaining acceptance work.
- TriGem becomes a visible manufacturer, with a sourced company history and
  the SX386 family: OEM 80386SX boards found in the Emerson Elite SX386/16
  and the CMS Enhancements ESP SX386M. TriGem is not an Olivetti brand; the
  SX386M only shares the Headland chipset with the PCS 386SX.
- TriGem SX386M:
  - The 8 MHz low-speed mode follows the BIOS: bits 2-3 of the keyboard
    controller output port, set by Ctrl+Alt+grey − / grey + and by the Setup
    "Start-up Speed" option. It is approximated with memory wait states; the
    CPU clock is not switched.
  - An audit against the BIOS disassembly confirms that the HT113 memory
    configuration, BIOS shadow and EMS-based video shadow follow the BIOS
    sequence for every documented RAM population.
- Olivetti GO714, GO717 and GO723 hard disk controllers, built on the
  WD1003 emulation and documented in Olivetti's service material. Their
  jumpers are fixed (1F0h, IRQ 14) and the machine provides the floppy
  controller. They now reset on a soft reset; before, a warm boot after Setup
  or diagnostics could report a controller error until a cold reset.
- Olivetti M380: the keyboard controller now speaks Olivetti's extended 8742
  protocol (A8h prefix), with eight hardware registers and a 64-byte NVRAM
  saved in the VM's nvr folder. The 384 KB of dedicated memory is mapped at
  800A0000h, where the BIOS looks for it, and register 2 switches the
  E0000h-FFFFFh shadow between RAM and ROM. BIOS 1.09 has no Setup in ROM;
  the SETUP program on the M280 System Test 2.02 disk works on the M380.
- Olivetti M250 and M250 E (BIOS PERB 1.03 and PDSF 1.06, reviewed from a
  disassembly):
  - The 1 MB memory model follows port 69h: bank enables during POST, the
    384 KB behind the hole at 100000h, and 256 KB of extended memory with
    the E0000h-FFFFFh shadow (384 KB without). The permanent
    60000h-to-80000h alias is removed; "RAM-REMAPPING" is only a sizing
    probe.
  - The Olivetti OVC 1.06 video BIOS is loaded; the Amstrad video ROM was
    loaded by mistake.
  - CMOS checksum seeded with the full value; disk types from the BIOS table
    (type 2 is 776/8/33, not the 766 in the service guide). Creation offers
    the Conner drives of the Setup table on the board's IDE interface.
- Olivetti PCS 286 and Triumph-Adler Dario 286: the 60000h-to-80000h
  reflection that BIOS 1.42 uses to tell 256 Kbit from 1 Mbit DRAM now follows
  keyboard-controller P2 bit 7 and only appears with 1 MB fitted. It was
  permanent, overlapping 128 KB of conventional memory and pushing 2 and
  4 MB boards into the 256 Kbit configuration. The CMOS checksum seed is also
  corrected.
- Olivetti M280: creation offers the GO723 (types 23 and 30) or GO717 (types
  6 and 7). BIOS 2.16 has no Setup in ROM; the sheet points to the SETUP on
  the System Test 2.02 disk. M28: creation uses the GO714.
- The Olivetti Prodest family sheet gains a sourced history and a model table
  (PC 128, PC 128 S, PC 1 and PC 1 HD).
- Machine sheets record the new firmware findings and the remaining
  limitations in the five languages.

Amstrad PC1512 is not part of the curated collection. Inherited emulator
machines remain selectable independently of the curated collection.

## Setup and firmware

The [alpha.1 setup guide](0.1.0-alpha.1.md) still describes ZIP extraction,
the independent BluMach VM library, configuration filenames and root ROM
folder selection. Each new machine sheet identifies its required firmware and
creation choices. Place entitled local firmware under the root ROM folder
selected in Preferences. The configuration combo requires both release
eligibility and locally available machine firmware; the catalogue can be
browsed without it.

The M380 keyboard-controller NVRAM is stored as
`olivetti_m380_kbc_nvram.bin` in the VM's nvr folder. A new file is erased
(FFh), so the first boot reports an invalid configuration until SETUP saves
one.

ROMs, BIOS, operating systems, applications and private preservation inputs
must not be included in source or binary release assets.

## Known limits

- The SX386M low-speed mode and the Olivetti memory clocks at 6 or 8 MHz are
  approximations, not cycle-accurate models of the HT113, GC101 or TACT82300
  chipsets.
- The Olivetti extended keyboard-controller protocol is enabled only on the
  M380. The M280 BIOS uses the same NVRAM, so its SETUP cannot yet save the
  configuration. M380 register 0 floppy bits and register 2 bit 7 are stored
  but not modelled.
- The GO controllers' jumpers are not modelled; the GO720 ESDI is not
  emulated; the GO714 drive table (the GO406's) has not been recovered.
- The M250 and M250 E disk jumpers P6, P8, P9 and P10 are not modelled.
- The SX386M RAM selector still allows undocumented 128 KB steps.
- The password keyboard-lock mode and the Setup typematic rate of the Olivetti
  PCS boards are not emulated.
- The new machines are experimental or partial unless their sheet states
  otherwise.

## Validation and follow-up

Automated catalogue and configuration tests are regression checks, not proof
of complete hardware fidelity. Checked during preparation with original
firmware (not distributed): TriGem SX386M created from its sheet boots; M380
POST reports 640 KB base, 3072 KB extended and 384 KB dedicated memory, keeps
a valid NVRAM after the M280 SETUP and boots MS-DOS 3.30a from a type 7 disk
on the GO717.

Further acceptance work:

1. TriGem SX386M: hard disk from the sheet, low-speed mode (hot keys and
   Setup), System+Video shadow and RAM populations.
2. M250 and M250 E: POST, Setup and System Test with the memory, video and
   CMOS fixes; Conner disk types.
3. PCS 286 and Dario 286: POST with 1, 2 and 4 MB and a fresh 40 MB disk
   profile.
4. M380: warm reset after SETUP. M280: GO723 type 23 with the System Test
   SETUP. M28: regression with the GO714.

Report bugs with version, host, model, BIOS selection, RAM, storage geometry
and reproduction steps. Enable a startup log with `--logfile path`
(`-L path`) when useful.
