# TriGem manufacturer mark

Wordmark cropped from the 2000 TriGem Computer Co., Ltd. logo traced by DigitalIceAge from the 2002 annual report. The date identifies the logo source. It is later than the SX386M catalogued here. The old local reconstruction has separate provenance.

[Wikimedia Commons source and rights statement](https://commons.wikimedia.org/wiki/File:TriGem_logo.svg)

Commons classifies the source as PD-textlogo. Trademark rights remain with
their respective holders. BluMach uses this mark to identify the manufacturer.
The asset retains its own status separately from BluMach's code licence.

The bundled PNG was rendered at 224 pixels high using rsvg-convert.
